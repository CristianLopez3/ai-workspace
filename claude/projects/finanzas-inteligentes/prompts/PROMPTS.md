# Comandos - Sistema de Finanzas Inteligentes

| Comando | Acción |
|---------|--------|
| `Generar reporte semanal finanzas` | Reporte completo de la semana |
| `En que gaste mas en [Categoria]?` | Desglose de una categoría |
| `Compara gastos esta semana vs anterior` | Comparación semanal |
| `Proyeccion: cuanto gastare el mes?` | Proyección al día 30 |
| `Que alertas tengo?` | Lista de alertas activas |
| `Dame recomendaciones de ahorro` | Análisis de últimas 4 semanas |
| `Status financiero` | Resumen rápido de la semana |
| `Alertas pendientes` | Categorías excedidas y acciones |
| `Cuanto me cuesta los gastos fijos?` | Desglose de fijos vs ingreso |
| `Dame el dashboard de finanzas` | Dashboard visual dark mode |
| `Cuales son mis comercios recurrentes?` | Comercios por frecuencia y monto |
| `Detalle completo de [Categoria]` | Todas las transacciones de la categoría |
| `Reporte de [Mes/Año]` | Reporte histórico de un mes |
| `Cuanto voy a ahorrar este año?` | Proyección anual vs meta |
| `Cambiar presupuesto de [Categoria] a [Monto]` | Ajuste de presupuesto (total debe ser $1,060,000) |

**Shortcuts:**
`/reporte` `/status` `/alertas` `/ahorro` `/proyeccion` `/gastos-fijos` `/comercios`
